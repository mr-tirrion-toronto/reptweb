SecuDrive for Windows

SecuDrive scans internal and removable drives, helps clean USB autorun files and fake shortcuts, and provides quarantine and recovery tools for suspicious or affected files.

Download SecuDrive Setup Review the source on GitHub

What it does

  • Scan Windows drives, USB flash drives, memory cards, and external disks.
  • Review detections and choose whether to clean, quarantine, or restore files.
  • Find common autorun files and fake shortcuts on removable drives.
  • Monitor file changes in real time and update malware signatures when online.
  • Keep encrypted recovery backups and a local activity record.

Requirements

For 64-bit Windows 10 or Windows 11. Setup requests administrator access so it can install the application and register its Windows security provider. An internet connection is needed for online signature updates.

Install on Windows

  1. Download the setup file from the official SecuDrive GitHub release.
  2. Open the downloaded file and approve the Windows administrator prompt if you intend to install it.
  3. Read and accept the terms, then finish the setup wizard.
  4. The Desktop shortcut is selected by default; clear that option in setup if you do not want one. SecuDrive is also added to the Start menu.

Publisher status: The current installer is not code-signed, so Windows may identify its publisher as unknown or show a SmartScreen warning. Check that the download comes from the official release link above and review the public source before choosing to run it.

Use and support

Choose a drive, run a scan, review the report, and inspect each proposed action before changing files. Keep a separate backup of important data. For help or to report a problem, use the SecuDrive issue tracker.
